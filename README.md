# Banking Management System 💳

A full-featured web-based banking management system that enables users to register, manage accounts, and track transactions across multiple branches with secure authentication.

## ⚙️ Tech Stack
- Frontend: React.js
- Backend: Spring Boot
- Database: MySQL
- Auth: JWT

## ✨ Features
- Register/Login with secure JWT auth
- Issue and manage credit/debit cards
- Track daily, monthly, yearly transactions
- Payment gateway simulation
- Admin dashboard

## 📦 Setup Instructions
1. Clone repo
2. Start MySQL server and update DB credentials
3. Run backend (`mvn spring-boot:run`)
4. Start frontend (`npm start`)
